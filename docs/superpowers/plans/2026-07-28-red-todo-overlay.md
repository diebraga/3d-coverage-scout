# Red To-Do Overlay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current freezing mesh recolor overlay with a smooth red-only overlay that disappears for fully captured surfaces.

**Architecture:** Keep `VoxelGrid` as the coverage source of truth. Remove SceneKit mesh recoloring from the live hot path and render capped red overlay nodes from incomplete voxel snapshots. Green voxels are never rendered.

**Tech Stack:** Swift 5, SwiftUI, ARKit, SceneKit, XCTest, xcodegen.

## Global Constraints

- No implementation should run before the user explicitly approves execution.
- Smooth camera and recording are higher priority than perfect triangle-accurate masking.
- The app never shows green overlay.
- Red means "this area still needs capture."
- Good/enough-captured areas render no overlay, including when the user returns later.
- The saved video remains plain camera video with no overlay baked in.
- Overlay refresh rate is at most 4 Hz.
- Visible red overlay nodes are capped at 800.
- Overlay work must not hold `VoxelGrid`'s lock while creating SceneKit geometry.
- Keep `CoverageScout.xcodeproj` generated by `xcodegen`; do not hand-edit it.

```swift
func incompleteSamples(limit: Int, near cameraPosition: SIMD3<Float>) -> [VoxelOverlaySample] {
    guard limit > 0 else { return [] }

    return classificationByVoxel.compactMap { coordinate, coverage in
        guard coverage != .green else { return nil }
        let center = SIMD3<Float>(
            (Float(coordinate.x) + 0.5) * Self.voxelSize,
            (Float(coordinate.y) + 0.5) * Self.voxelSize,
            (Float(coordinate.z) + 0.5) * Self.voxelSize
        )
        return VoxelOverlaySample(coordinate: coordinate, center: center, coverage: coverage)
    }
    .sorted { simd_distance_squared($0.center, cameraPosition) < simd_distance_squared($1.center, cameraPosition) }
    .prefix(limit)
    .map { $0 }
}
```

### Task 2: Add Capped Red Overlay Renderer

**Files:**
- Create: `Sources/AR/RedTodoOverlayRenderer.swift`

**Interfaces:**
- Consumes: `[VoxelOverlaySample]`
- Produces:
  - `final class RedTodoOverlayRenderer`
  - `let rootNode: SCNNode`
  - `func update(samples: [VoxelOverlaySample])`

- [ ] **Step 1: Implement renderer**

Create `Sources/AR/RedTodoOverlayRenderer.swift`:

```swift
import SceneKit

final class RedTodoOverlayRenderer {
    static let maxVisibleNodes = 800
    static let maxAddsPerUpdate = 150
    static let maxRemovesPerUpdate = 300

    let rootNode = SCNNode()
    private var nodesByCoordinate: [VoxelCoordinate: SCNNode] = [:]

    func update(samples: [VoxelOverlaySample]) {
        let capped = Array(samples.prefix(Self.maxVisibleNodes))
        let wanted = Set(capped.map(\.coordinate))

        var removed = 0
        for coordinate in nodesByCoordinate.keys where !wanted.contains(coordinate) {
            guard removed < Self.maxRemovesPerUpdate else { break }
            nodesByCoordinate.removeValue(forKey: coordinate)?.removeFromParentNode()
            removed += 1
        }

        var added = 0
        for sample in capped where nodesByCoordinate[sample.coordinate] == nil {
            guard added < Self.maxAddsPerUpdate else { break }
            let node = makeNode(at: sample.center)
            nodesByCoordinate[sample.coordinate] = node
            rootNode.addChildNode(node)
            added += 1
        }
    }

    private func makeNode(at center: SIMD3<Float>) -> SCNNode {
        let geometry = SCNBox(width: 0.09, height: 0.09, length: 0.09, chamferRadius: 0.005)
        let material = SCNMaterial()
        material.diffuse.contents = UIColor(red: 1.0, green: 0.05, blue: 0.05, alpha: 0.45)
        material.lightingModel = .constant
        material.blendMode = .alpha
        geometry.materials = [material]

        let node = SCNNode(geometry: geometry)
        node.simdPosition = center
        return node
    }
}
```

Add:

```swift
private func refreshRedOverlay(cameraPosition: SIMD3<Float>, timestamp: TimeInterval) {
    guard timestamp - lastOverlayRefresh >= minOverlayRefreshInterval else { return }
    lastOverlayRefresh = timestamp

    let samples = withVoxelGridLock {
        voxelGrid.incompleteSamples(limit: RedTodoOverlayRenderer.maxVisibleNodes, near: cameraPosition)
    }

    DispatchQueue.main.async { [weak self] in
        self?.redOverlayRenderer.update(samples: samples)
    }
}
```
